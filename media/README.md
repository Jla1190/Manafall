# Manafall media

Official stills and TikTok clips for [@manafalltiktoc](https://www.tiktok.com/@manafalltiktoc).

## Drop gameplay here

Put short vertical (or 16:9) `.mp4` files in `clips/`. The twice-daily poster picks the oldest clip that has not been posted yet, then rotates caption tactics in `tiktok/tactics.json`.

Gameplay footage outperforms stills. Keep clips:

- 8–25 seconds
- H.264 + AAC
- No one else's copyrighted music
- No debug overlays if you can hide them
